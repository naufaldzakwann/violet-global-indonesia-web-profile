# PT Violet Global Indonesia — Web Profile (vgi.web.id)

Company profile website for **PT Violet Global Indonesia** — deep tech, digital
intelligence, cybersecurity, consulting, and green energy.

- **Domain:** https://vgi.web.id
- **Stack:** Next.js 16 (App Router, Turbopack), React 19, TypeScript, Tailwind CSS v4
- **Language:** English only (v1, static — no CMS / database)

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Routes

| Route | Page |
| --- | --- |
| `/` | Homepage (hero → platforms → cybersecurity → consulting → green energy → contact CTA) |
| `/about` | Company profile, vision, mission |
| `/platforms` | Narativa-X, Blockchain Analytics, Enterprise Automation |
| `/cybersecurity` | Services, infrastructure, training & compliance |
| `/consulting` | Market entry, technology, business development, market enabler |
| `/green-energy` | Approach, pipeline concepts, smart waste |
| `/procurement` | IT procurement categories & partners |
| `/contact` | Inquiry form (mailto) + company info |

## Build & Deploy

```bash
npm run build
npm run start
```

Deployed on [Vercel](https://vercel.com). Custom domain: `vgi.web.id`.
SEO included: per-page metadata, `sitemap.xml`, `robots.txt`, JSON-LD Organization.
